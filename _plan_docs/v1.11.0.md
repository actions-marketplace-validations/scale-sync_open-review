# v1.11.0 — first three public SDKs

## Three features

1. **Go SDK.** Expose a small importable Go API for review/scan and typed results; publish the tagged public module for Go tooling and documentation discovery.
2. **TypeScript 7 SDK.** Typed Node API and optional CLI installer use the stable engine contract; publish to npm only after package and account checks.
3. **Python SDK.** Typed Python API and optional CLI installer use the same contract; publish to PyPI only after wheel/source package and account checks.

## Implementation boundary

Add a public Go package only after internal APIs stabilize. Put language bindings under `sdk/`. Bindings may invoke a verified Go binary; they do not reimplement the reviewer. Version the contract independently and state OS/architecture support.

## Release gate

Cross-language fixture parity, install from built artifacts, package-content review, checksums, license, account/ownership, and public-source availability. Registry publication is an explicit release step after these checks, never a side effect of earlier tags.
