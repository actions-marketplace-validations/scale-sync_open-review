# v1.15.0 — integration packaging and host reach

## Added

1. **IDE distribution.** Publish repeatable VS Code and JetBrains install/update instructions and build artifacts, while keeping both adapters on the shared CLI contract and human-confirmed suggestion flow.
2. **CI integration reach.** Add maintained Bitbucket and Codeup examples only with an owner for each adapter; preserve the existing GitHub, GitLab, GitFlic, and Gerrit examples without changing their result contract.
3. **Cross-host contract checks.** Run one pinned CLI contract matrix across MCP, ACP, VS Code, JetBrains, host-agent skills, and all four SDKs to detect drift before release.

## Scope and proof

The VS Code extension must typecheck, test, and package from a clean checkout. The JetBrains plugin must compile, run unit tests, and produce a reproducible plugin artifact. CI examples must validate permissions, secret handling, partial-review exit codes, artifact retention, and provider-key rotation without live credentials. The cross-host matrix must assert identical preview coverage and schema-compatible findings for the same fixture. Marketplace publication remains separate from local packaging until publisher accounts and ownership are confirmed.
