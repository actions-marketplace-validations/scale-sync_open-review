# v0.9.0 — usable model setup and predictable cost

## Three features

1. **Provider setup.** Interactive and noninteractive configuration for built-in and custom OpenAI-compatible, Anthropic, and Gemini endpoints, with per-run provider/model overrides and a connectivity test.
2. **Output contracts.** Human-readable text, stable JSON, file output, quiet agent mode, shell completion, explicit exit/status codes, and separate stdout/stderr for machine use.
3. **Cost and time controls.** Distinct prompt/output ceilings, aggregate token budget, request timeout, group deadline, usage totals, and partial-result status.

## Implementation boundary

Keep provider transport in `review/internal/llm/`; config resolution stays in `review/internal/config/`. One resolved model identity enters the review request. Output formatting consumes results and never changes review decisions.

## Release gate

Test credential redaction, malformed config, streaming interruption, untouched output files on early failure, budget exhaustion, and model overrides. Reconcile existing `1.0.0` package metadata before earlier tags, not here.
