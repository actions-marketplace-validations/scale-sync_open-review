# v0.8.0 — preserve our deeper review strengths

## Three features

1. **Sandboxed deep review.** Retain explicit deep/RLM verification, read limits, and audit events while moving orchestration behind the Go review contract. Sandboxed execution stays isolated from credentials and network by default.
2. **Linter fusion.** Run the existing ESLint, Ruff, Semgrep, ShellCheck, and Gitleaks adapters only where tooling is available; attribute and deduplicate findings against model output. Action and CLI paths agree.
3. **Review-state continuity.** Track new, open, and resolved findings across PR pushes; prevent duplicate comments and preserve earlier conversations.

## Implementation boundary

Use concrete linter adapters behind one runner, not a generic plugin framework. The deep path may retain a narrow TypeScript/Deno bridge temporarily; Go owns the request, coverage, and final result. State changes remain in the GitHub adapter.

## Release gate

Test sandbox escapes and timeouts, missing linter binaries, duplicate findings, repeated webhook events, and failure recovery. Run the relevant suites and a live PR smoke before calling Action parity complete.
