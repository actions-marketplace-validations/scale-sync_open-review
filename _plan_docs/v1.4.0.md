# v1.4.0 — resumable review history

## Three features

1. **Append-only session trace.** Persist input identity, model requests, tools, findings, warnings, and coverage as redacted versioned events.
2. **Safe resume.** Reuse completed file/group work only when diff, rules, provider, model, and runtime configuration fingerprints match; otherwise rerun it.
3. **Session CLI.** List, show, inspect comments, compare, export, and delete sessions with repository ownership checks.

## Implementation boundary

`review/internal/session/` owns persistence and identity. The reviewer emits typed events; it does not know filesystem layout. A failed write is surfaced, and a partial run cannot claim complete coverage.

## Release gate

Crash/restart, malformed event, stale fingerprint, concurrent run, deletion scope, and secret-redaction tests. A resumed run must match a fresh run on the same fixture.
