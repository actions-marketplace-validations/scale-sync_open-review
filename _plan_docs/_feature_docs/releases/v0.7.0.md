# v0.7.0 — Go review path with GitHub parity

## Three features

1. **Go fast review engine.** Run model-backed review from normalized changes and return validated findings plus the v0.6.0 coverage manifest. One Go implementation owns this path.
2. **GitHub Action adapter.** Use TypeScript 7 for event/auth/comment plumbing and invoke the Go engine through `review/schema/`. Preserve draft/skip behavior, CLI `--submit`, inline comments, and the sticky summary.
3. **PR conversation.** Preserve `@open-review` thread Q&A and local `ask` with bounded repository context, citations, follow-up suggestions, and loop protection as distinct product capabilities.

## Implementation boundary

Add `review/internal/llm/` and Action contract code. Pass secrets through environment, never persisted request JSON. Product fast-review callers use Go. Keep the TypeScript implementation and its tests as comparison material until full parity can be demonstrated; no production caller uses it. Keep the deep-review path until v0.8.0.

## Release gate

Run CLI and Action contract fixtures, TypeScript 7 typecheck/build/tests, malformed-model-output tests, and packaged Action smoke tests. A live GitHub PR smoke test is required before claiming live posting proof. Verify old review links and state are not lost. This is the third release; SDK work may begin only after this tag, but is scheduled after API stabilization.
