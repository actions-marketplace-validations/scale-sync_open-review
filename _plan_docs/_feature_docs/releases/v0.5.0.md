# v0.5.0 — review code before it reaches a pull request

## Three features

1. **Workspace review.** Review staged, unstaged, and untracked changes from the local working tree. Do not require a PR URL. Verify untracked file content and empty workspaces.
2. **Branch comparison.** Review a selected base and head using the merge base. Report the actual refs and SHA values used.
3. **Single-commit review.** Review one commit, including root, merge, rename, deletion, and empty-commit behavior.

## Implementation boundary

Start `cmd/open-review/`, `review/internal/gitcmd/`, `review/internal/agent/`, `review/internal/model/`, and `review/schema/`. The Go CLI temporarily sends normalized local changes through the contract to the existing TypeScript reviewer; v0.7.0 replaces this bridge with the Go reviewer. Git execution and path validation belong to `gitcmd/`; the reviewer sees normalized file changes only. The CLI name becomes `open-review`.

## Release gate

Use temporary Git repositories as tests for all three modes, including filenames with spaces and paths outside the repo. Run Go tests, existing TypeScript build/typecheck/tests, and CLI smoke checks. Publish only after the three features pass; release notes distinguish local Git proof from GitHub proof.
