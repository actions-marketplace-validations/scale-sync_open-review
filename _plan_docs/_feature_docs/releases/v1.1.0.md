# v1.1.0 — controlled codebase context

## Three features

1. **Read-only context tools.** Bounded file and diff reads at the reviewed revision, with path and size validation.
2. **Iterative review.** Bounded repository search/discovery, structured comment/completion tools, and low/medium/high review rounds with early stopping.
3. **Context compression.** Preserve the initial task and recent evidence while summarizing older tool rounds when the prompt budget requires it.

## Implementation boundary

Put tool handlers behind explicit read capabilities in `review/internal/tool/`; no unrestricted shell tool. Model output is parsed and checked before it becomes a tool call or finding. Compression does not replace coverage accounting.

## Release gate

Test path escape, symlink, binary/large files, tool-call limits, cancellation, malformed outputs, and summary fidelity using fixed transcripts. Measure token and latency changes locally.
