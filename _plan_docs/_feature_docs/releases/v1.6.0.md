# v1.6.0 — useful CI results

## Three features

1. **Mature GitHub delivery.** Checkpoint-aware incremental PR reviews, sticky summaries, inline comments, and optional GitHub App identity avoid duplicate or destructive posting.
2. **Other CI paths.** Documented, tested GitLab, GitFlic, and Gerrit pipelines consume the CLI contract and post or archive results with least-privilege credentials.
3. **SARIF and code scanning.** Emit valid SARIF 2.1.0 with stable fingerprints for CI/code-scanning upload; preserve text and JSON output.

## Implementation boundary

Keep hosting-specific adapters outside `review/`. The Go engine never owns CI tokens. Posting code maps one canonical finding to each platform's position model and rejects invalid positions.

## Release gate

Contract tests for every CI adapter, SARIF schema validation, duplicate-run fixtures, token-permission checks, and one live smoke per available platform. Label unperformed platform tests explicitly in release notes.
