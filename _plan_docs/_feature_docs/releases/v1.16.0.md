# v1.16.0 — benchmark proof and governed team memory

## Added

1. **AACR-Bench publication run.** Execute all 200 pull requests from the pinned 50-project, 10-language corpus with a recorded model, provider, effort, reviewer revision, and dataset checksum.
2. **Quality report.** Publish precision, recall, F1, line precision, noise, mean review time, and token usage only after every generated finding has a human judgment. Include language-level results and the raw run metadata.
3. **Governed durable learnings.** Add provenance, approval state, expiry, and per-rule impact metrics to repository learnings while retaining private storage, capacity pruning, and prompt-injection rejection.

## Scope and proof

The benchmark gate fails on partial runs, changed datasets, missing judgments, schema-incompatible provider output, or absent model identity. The published report must link the reviewer revision and SHA-256 dataset checksum and distinguish measured results from unverified claims. Learning tests must cover provenance, approval transitions, expiry, pruning, import/export, prompt-injection rejection, and isolation between repositories. No leaderboard number is published until the full adjudication set is complete.
