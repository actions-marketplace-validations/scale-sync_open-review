# v1.12.1 — SDK registry publication

## Three features

1. **Public SDK packages.** Publish the TypeScript package `@scalesync/open-review`, the Python package `openreview-sdk`, and the Rust crate `openreview-sdk` at version `1.12.1`.
2. **Go module release.** Verify the Go SDK through the root module tag `v1.12.1` and package path `github.com/scale-sync/open-review/sdk/go`.
3. **Release history.** Show `v1.12.1` as the latest entry at the top of the website release history.

## Release gate

The release workflow builds and tests all SDKs, publishes the npm, PyPI, and crates.io packages, verifies the Go module tag, and creates the GitHub Release with checksummed binary assets.
