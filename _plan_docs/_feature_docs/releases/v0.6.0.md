# v0.6.0 — make review scope observable

## Three features

1. **Faithful diff model.** Preserve changed hunks, old/new paths, copy/move detection, rename, delete, binary, and untracked metadata without silently dropping content.
2. **Deterministic file selection.** Apply user exclusions, supported-file rules, generated/dependency filters, and size limits with a recorded reason for every excluded file. Explicit includes can override defaults but not unsafe inputs.
3. **Coverage manifest and preview.** Show selected/skipped files before an LLM call. After review, mark each file reviewed, partial, failed, or skipped. Fix the current Action `max-files` cap so it filters the actual diff.

## Implementation boundary

Add selection and manifest code inside `review/internal/agent/` while it remains small; `review/internal/diff/` owns diff parsing. Split only if real callers require a separate package. The manifest is computed from normalized input before dispatch and is independent of model output. Extend the JSON contract under `review/schema/` with coverage states.

## Release gate

Fixture tests cover filter precedence, renames, empty diffs, large files, and budget truncation. An Action contract test proves excluded files never reach the model. Run Go and TypeScript suites; release notes include the coverage states seen in fixtures.
