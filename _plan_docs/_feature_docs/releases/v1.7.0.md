# v1.7.0 — protocol integration

## Three features

1. **MCP client.** Attach explicitly configured local or remote tool servers to a review with tool allowlists, timeouts, and secret isolation.
2. **MCP server.** Expose review/scan through a narrow callable protocol surface so external clients can invoke the same engine and receive the same result schema.
3. **Experimental ACP adapter.** Offer review/scan, progress, cancellation, and finding navigation through a separate stdio process; mark this adapter experimental until interoperability tests pass.

## Implementation boundary

Protocol adapters translate requests only. They do not import each other's internals or fork review logic. Keep tool permissions explicit; network, process launch, and repository access are validated at the adapter boundary.

## Release gate

Protocol conformance, cancellation, malformed-message, tool-denial, timeout, and cross-platform process tests. A local client must produce the same review result through CLI and protocol entry points.
