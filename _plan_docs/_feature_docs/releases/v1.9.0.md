# v1.9.0 — provider and operational breadth

## Three features

1. **Broader provider support.** Add tested Azure OpenAI, Amazon Bedrock, custom endpoints, per-run model selection, an optional ChatGPT sign-in preview, credential commands, retries, and prompt-cache affinity where supported.
2. **Observability.** Opt-in OpenTelemetry traces, metrics, and events report latency, tokens, tool use, and failures without prompt or source content by default.
3. **Privacy and security controls.** Validate secret-path exclusions, redaction, retention/deletion, tool and sandbox permissions, telemetry content policy, and safe local state permissions.

## Implementation boundary

Provider differences stay inside `review/internal/llm/`; review code sees one typed call/result. Telemetry observes events and cannot change outcomes. Credential stores are separate from session logs. Account sign-in remains gated until its auth and terms are independently verified.

## Release gate

Provider contract fixtures, live connectivity checks where credentials exist, injected failures, secret-scrub tests, telemetry-off baseline, and privacy audit. Release notes mark any provider that was not live-tested.
