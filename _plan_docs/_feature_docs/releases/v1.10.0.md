# v1.10.0 — deeper review and retained knowledge

## Three features

1. **Optional high-recall mode.** More review rounds and broader context for high-risk changes, with explicit token/time cost and no silent change to normal review.
2. **Durable feedback learnings.** Accepted/dismissed findings and explicit feedback become inspectable, deletable, repository-scoped guidance; ephemeral Action runners can retrieve authorized state.
3. **Localization, documentation, and website.** Launch a basic product and documentation website; localize CLI/IDE guidance and docs for selected languages. Keep command names, JSON keys, and release evidence stable across locales. Use Next.js with TypeScript 7 and Tailwind CSS if its production build passes; otherwise use React with TypeScript 7 and Tailwind CSS.

## Implementation boundary

High-recall is a policy on the same engine, not a second engine. Learnings are data with source, scope, expiry, and deletion; no unreviewed prompt injection. Localization stays outside model and coverage logic. The website reads shipped documentation and release notes; it does not run a second review engine.

## Release gate

Measure precision/recall and cost on a fixed local corpus, verify learning isolation and deletion, and test every supported locale's command and output contract. Build the website with TypeScript 7 and verify its production output. No external benchmark is claimed as our result.
