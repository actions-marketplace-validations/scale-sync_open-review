# v1.0.0 — coordinated review of related changes

## Three features

1. **Related-file grouping.** Bundle related files for shared context; fall back to single-file groups on grouping failure. No file disappears from coverage.
2. **Bounded parallelism.** Run groups concurrently under one global budget and deterministic result ordering; isolate group errors.
3. **Conditional plan phase.** Use a short planning pass for large changes only; small changes skip its model cost.

## Implementation boundary

Keep grouping a policy in `review/internal/agent/` until there is a real reason to split it. Model-suggested groups cannot alter the deterministic selection manifest. The coordinator owns the worker limit and final collector.

## Release gate

Test overlarge groups, duplicate/missing assignments, cancellation, race behavior, partial failure, and budget exhaustion. Run Go race tests. The v1.0.0 label signals a stable review contract, not a switch to registry distribution.
