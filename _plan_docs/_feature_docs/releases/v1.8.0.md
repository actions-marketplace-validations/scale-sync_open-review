# v1.8.0 — reviews inside developer tools

## Three features

1. **Host-agent delegation.** Preview selected files and resolved rules, then hand a structured review task to an authorized coding agent without requiring this product's own model key.
2. **Portable agent integrations.** Ship a review skill plus thin commands/plugins for Claude Code, Codex, Cursor, Kimi Code, OpenCode, and compatible hosts; reuse the same CLI contract.
3. **IDE extensions.** TypeScript 7 VS Code and Kotlin JetBrains adapters show file preview, live progress, inline findings, apply/dismiss/false-positive actions, and provider setup. The JetBrains adapter begins as experimental if platform parity is incomplete.

## Implementation boundary

`integrations/agents` and `extensions/` are adapters. They never reimplement selection, rules, or review prompts. Editor actions that modify code require explicit user action and preserve undo. UI transport is platform-specific; shared message schema is versioned.

## Release gate

Skill/command contract tests, no-key delegation tests, IDE smoke tests for both platforms, cancellation, path navigation, and two-way triage synchronization. No auto-apply of code changes.
