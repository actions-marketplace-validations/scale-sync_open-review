# v1.3.0 — precise, actionable comments

## Three features

1. **Comment relocation.** Match cited snippets to diff lines and use a bounded fallback for ambiguous anchors; keep unanchored findings visible without posting invalid inline positions.
2. **Finding verification.** Recheck candidate findings against source/diff evidence, collapse duplicates, and expose filtered or uncertain outcomes in diagnostics.
3. **Code suggestions.** Preserve severity, explanation, cited range, and optional replacement code in CLI, JSON, and GitHub comments.

## Implementation boundary

One finding validator sits between model/linters and every output channel. Formatting never upgrades an uncertain result to a confirmed issue. No automatic code application occurs in this release.

## Release gate

Test repeated text, moved code, multi-line edits, unchanged lines, invalid line numbers, false-positive samples, and GitHub suggestion syntax. Compare posted positions against the exact head SHA.
