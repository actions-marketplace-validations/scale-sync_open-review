# v1.12.1 — SDK registry publication

## Added

1. **Registry publication.** Publish `@scalesync/open-review` on npm, `openreview-sdk` on PyPI, and the `openreview-sdk` crate on crates.io at version `1.12.1`.
2. **Go SDK release.** Publish the Go SDK through the `v1.12.1` module tag after the other SDK registries complete.

## Distribution and proof

The release workflow builds and tests each SDK, publishes npm, PyPI, and crates.io packages using repository secrets, then verifies the tagged Go module before creating the GitHub Release. The website release history lists `v1.12.1` first.
