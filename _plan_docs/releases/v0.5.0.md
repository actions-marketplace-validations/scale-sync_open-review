# v0.5.0 — local Git review

Published on GitHub after the three features pass the release checks. The commit dates for this batch start on October 5, 2026, as requested; the GitHub release date is the actual publication date.

## Added

1. **Workspace review:** staged, unstaged, and untracked files in one review; clean workspaces return an empty result without calling a model.
2. **Branch comparison:** compare a selected head with the merge base of a selected base, and report the selected refs and their exact commit IDs.
3. **Single-commit review:** compare a commit with its first parent; root commits use Git's empty tree. Rename, deletion, merge, and empty commits have defined behavior.

## Use from source

Requires Go 1.23+, Node.js 20+, pnpm, Git, and one supported model API key for nonempty reviews.

```bash
pnpm install --frozen-lockfile
pnpm build
go run ./cmd/open-review review --repo /path/to/repository --workspace
go run ./cmd/open-review review --repo /path/to/repository --base main --head my-branch
go run ./cmd/open-review review --repo /path/to/repository --commit HEAD --output json
```

The Go CLI runs Git and hands the normalized diff to the existing TypeScript reviewer through `cli/dist/local-bridge.mjs`. Run it from this source checkout, or set `OPEN_REVIEW_BRIDGE` to the built bridge path. This is a source release; no package registry publication is part of v0.5.0.

## Verification

The release gate runs Go tests for all three modes and Git edge cases, plus the existing TypeScript lint, build, typecheck, and test suite. Live model responses and GitHub Actions are separate checks; do not infer either from local tests.
