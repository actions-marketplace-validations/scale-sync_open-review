# v1.5.0 — whole-file review and finding triage

## Added

1. **Full-file scan.** `review --scan PATH` reviews a file, directory, or repository without a Git diff. Preview shows selected and skipped files before a model call. Exact-input scan sessions can reuse completed groups; changed content invalidates that reuse.
2. **Local session viewer.** `sessions serve` binds to a numeric loopback address and shows saved reviews, events, result coverage, triage, and before/after finding comparisons. It exports the stored report without contacting a provider.
3. **Finding triage.** `sessions triage` records `fixed`, `ignored`, `false_positive`, or `open` in a private file separate from the original review result. An explicit `--pr-url` and `--thread-id` can resolve or reopen a matching GitHub review thread using a supplied token.

## Scope and proof

Go owns scan selection, session storage, viewer rendering, and CLI triage. The GitHub sync adapter validates pull request URL, finding path, line, title, and token permissions before mutation. Unit tests cover scan without Git, preview, resume, binary and unsafe files, viewer scope and stored HTML escaping, comparison, triage transitions, original-result preservation, and a mocked GitHub thread. Live PR thread mutation, paid model quality, and cross-platform binaries were not tested in this release. No package registry publication is included.
