# v0.8.0 — deep verification, linter fusion, and review continuity

The commit for this batch uses October 8, 2026 as its Git author and committer date. GitHub shows the actual publication date.

## Added

1. **Go deep review:** local `--deep`, PR CLI `--mode rlm`, and `@open-review rlm` use one Go review contract. Up to four investigation cycles can run short TypeScript checks in a Deno sandbox with a 15-second limit, bounded output, a private temporary file, and no network, environment, subprocess, or write access. Go validates final citations and records audit events. If Deno is absent, the result explicitly says verification was unavailable.
2. **Linter fusion:** available ESLint, Ruff, Semgrep, ShellCheck, and Gitleaks binaries can add diagnostics for selected changed lines from a matching checkout. Overlaps with model findings are attributed to both sources. Missing tools and failures appear in the audit; detected secret values are not copied into comments. Action events leave repository linters disabled by default unless a trusted workflow explicitly sets `OPEN_REVIEW_TRUSTED_LINTERS=true`.
3. **Review continuity:** repeated PR events reuse the existing summary without deleting it or adding a start comment. Inline findings carry stable markers, so a retry after a failed summary write does not repost the same finding. New, open, and resolved states remain visible across pushes.

## Compatibility and limits

The previous TypeScript deep and linter paths remain in source for comparison, while current product review callers use Go. The bundled Action targets Linux x64. Deno must be installed before an Action event to enable executable deep checks; it is never installed during a model-key step. Linters run in the local Go CLI when binaries are available, and in Actions only after explicit trusted-checkout opt-in.

The release gate runs Go tests and vet; TypeScript 7 lint, build, typecheck, and tests; real Deno sandbox-denial checks in GitHub CI; retry and deduplication tests; and packaged Action and Go executable smoke checks. Live model quality and live GitHub PR posting still require credentials and a test PR. No npm, PyPI, crates.io, or Go registry publication is part of this release.
