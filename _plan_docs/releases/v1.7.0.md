# v1.7.0 — protocol adapters

## Added

1. **MCP client.** An opt-in local JSON configuration attaches allowed local or HTTPS tools to a Go review. Calls use static, user-configured arguments, bounded timeouts and output, and a restricted subprocess environment. The model can select a named tool but cannot supply outbound arguments.
2. **MCP server.** `mcp serve --repo PATH` exposes the Go engine through a review tool with workspace, branch, commit, and full-file scan modes. Preview returns selection and rules without a model call.
3. **Experimental ACP adapter.** `acp serve --repo PATH` accepts an ACP v1 stdio session for the configured repository, reports progress and finding locations, and supports `session/cancel`. Its result uses the same Go review engine.

## Scope and proof

The full Go race suite, vet, TypeScript lint/build/typecheck and 356 tests, CI adapter tests, and local MCP/ACP protocol tests passed. The CLI and MCP preview returned the same selected file. The ACP fixture covered initialization, malformed input, prompt completion, and cancellation. Linux and Windows Go cross-compilation passed; CI will test Linux after push. External MCP servers, editor interoperability, live model quality, and Windows process execution were not tested. ACP remains experimental. No package registry publication is included.
