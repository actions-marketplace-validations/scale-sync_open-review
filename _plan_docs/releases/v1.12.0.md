# v1.12.0 — Rust SDK and binary distribution

## Added

1. **Rust SDK.** `openreview-sdk` offers typed review and scan results over the Go CLI, contract v2 validation, and a timeout that terminates the child process.
2. **Binary assets.** The release workflow builds Go binaries for Linux amd64/arm64, macOS amd64/arm64, and Windows amd64. It generates SHA-256 checksums and one manifest tying asset hashes, SDK versions, and contract version.
3. **Cross SDK check.** CI builds the CLI and verifies an empty scan through Go, Node, Python, and Rust, then packages Node, Python, and Rust artifacts.

## Distribution and proof

The Unix install script downloads the matching GitHub Release asset and verifies its SHA-256 digest before installation. Cross compilation verifies target builds; runtime checks on each operating system and registry retrieval still require release infrastructure. Windows has a ZIP asset but no install script. Homebrew distribution depends on formula ownership and is not included in this release.
