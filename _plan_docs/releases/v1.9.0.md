# v1.9.0 — provider and operational breadth

## Added

1. **Broader provider support.** Support for Azure OpenAI and Amazon Bedrock endpoints alongside OpenAI, Anthropic, Gemini, and OpenRouter. Includes transient error backoff/retry handling (HTTP 429/5xx), prompt-caching headers for Anthropic, and per-provider credential resolution with CLI configuration flags.
2. **Observability.** Opt-in telemetry span recording capturing operation names, model provider/names, latency, token metrics, and error status. Telemetry strictly redacts source code, diffs, patches, secrets, and prompt payloads by default.
3. **Privacy and security controls.** Automated secret path detection and exclusion (`.env*`, `.pem`, `.key`, `id_rsa`, etc.) from review file selection, regex-based token and API key redaction (`sk-`, `ghp_`, `AKIA`, `xoxb-`, etc.), and safe local state isolation.

## Scope and proof

Provider contract fixtures and mock servers verified Azure OpenAI chat completions format, Bedrock invoke model format, transient retry loops, and Anthropic prompt caching headers without live cloud credentials. Telemetry span tests verified attribute capture and strict content blocking. Privacy tests verified token sanitization and secret file exclusion during agent file selection. Full test suites (`go test ./...`, `pnpm test`, `pnpm typecheck`, `pnpm lint`, agent integration tests) passed cleanly.
