# v1.4.0 — resumable local review sessions

## Added

1. **Append-only session trace.** An opted-in local review records versioned model, tool, finding, coverage, audit, and final-status events without saving prompts or provider credentials in the event stream. Private result files retain findings for inspection.
2. **Safe resume.** Completed file groups and a successful plan can be reused on an identical pinned review. The fingerprint covers input, rules, effective provider and model, limits, runtime, and executable. Workspace reviews and changed inputs do not reuse output.
3. **Session CLI.** `sessions list`, `show`, `inspect`, `compare`, `export`, and `delete` work within a specified repository and session directory. Export writes atomically to a private file.

## Scope and proof

Go owns session storage and review reuse. The GitHub Action does not retain sessions on ephemeral runners. The CLI enables storage with `review --session-dir PATH`; no provider key is needed to read stored sessions. Local tests cover reuse without another model call, changed-rule invalidation, malformed records, repository ownership, export, and deletion. Live model quality and live platform posting are separate checks.

No package registry publication is included.
