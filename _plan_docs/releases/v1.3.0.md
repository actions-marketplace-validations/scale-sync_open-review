# v1.3.0 — precise, actionable comments

The commit for this batch uses October 13, 2026 as its Git author and committer date. GitHub shows the actual publication date.

## Added

1. **Comment relocation:** The Go validator matches an exact cited code snippet against added diff lines within 20 lines of the reported position. A unique match relocates the citation and its range. Repeated or missing snippets remain unanchored and visible for checking.
2. **Finding verification:** One pass after model and linter findings checks changed-line evidence, removes malformed and duplicate findings, and records filtered, uncertain, and relocated counts in the review audit. It verifies the citation, not the finding's semantic correctness. Uncertain findings remain in local output and the PR summary without an inline position.
3. **Code suggestions:** Findings carry severity, explanation, cited range, and optional replacement code through Go JSON, CLI text/Markdown, and GitHub comments. A verified, fully added multi-line range posts with GitHub's range fields and a suggestion block. The poster checks the current PR head against the reviewed SHA and pins the review to that commit.

The Action remains bundled for Linux x64. No package registry publication is included. Local checks cover relocation, repeated text, invalid lines, unchanged lines, duplicate findings, multi-line suggestions, and a moved PR head. Live model quality, live GitHub posting, and GitHub Release completion still require platform checks.
