# v1.8.0 — reviews inside developer tools

## Added

1. **Host-agent delegation.** `open-review delegate` emits one bounded review task from the same selected diff and resolved rules used by the Go engine. It needs no product model key and never includes excluded content.
2. **Portable agent integrations.** A single review skill installs into supported coding-agent skill locations. Each host runs the same preview and delegation contract instead of maintaining a second review implementation.
3. **IDE extensions.** The TypeScript 7 VS Code extension and experimental Kotlin JetBrains extension preview scope, run reviews, navigate findings, synchronize triage, and require confirmation before applying a suggestion.

## Scope and proof

Delegation and installer contract tests passed without a model key. The VS Code adapter typecheck and three unit tests passed. The JetBrains adapter compiled, ran its unit test, and packaged successfully with Java 21 and Gradle 9.8.0. CI runs both adapter suites plus the agent installer tests. The JetBrains adapter remains experimental because it has not been manually exercised inside a desktop IDE. A provider setup or review can send selected source to the configured model provider; preview and delegation do not.
