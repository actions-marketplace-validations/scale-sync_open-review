# v1.0.0 — coordinated review of related changes

The commit for this batch uses October 10, 2026 as its Git author and committer date. GitHub shows the actual publication date.

## Added

1. **Related-file grouping:** selected patches from the same folder share one review call when they fit the 40 KB group cap. Oversized groups split into smaller groups. Every selected file remains assigned exactly once; malformed or missing patch assignments fail visibly.
2. **Bounded parallelism:** up to three groups run at once. They share the same reserved token budget and review deadline. Findings are collected in selected-group order, even when requests finish in a different order. A group failure produces a partial result if another group succeeds; completed files retain reviewed coverage.
3. **Conditional plan phase:** changes with at least three files or 16 KB of selected diff get a short model planning pass when at least 10,000 tokens remain. The plan supplies a review focus only and cannot change selected files or groups. Small or budget-constrained changes skip the call; malformed plans fall back to the fixed grouping policy.

## Compatibility and limits

The Go JSON contract stays at version 2. Its trace adds `groups`, `groupsCompleted`, and `plan`; no input fields changed. The worker limit is three and the existing maximum of 20 group calls remains. The Action continues to avoid posting a partial result as a complete review. This release is from source and the GitHub Action tag; no package registry publication is included.

The release gate covers grouping and assignment errors, cancellation, isolated group failure, deterministic findings, concurrent budget reservation, full Go race tests and vet, TypeScript 7 build/typecheck/lint/tests, packaged Action and Go executable checks, and GitHub CI. Live model quality and live pull request posting require credentials and a test PR.
