# v0.7.0 — Go fast review and PR conversation

The commit for this batch uses October 7, 2026 as its Git author and committer date. GitHub shows the actual publication date.

## Added

1. **Go fast review engine:** the local CLI and PR callers use one Go path for file selection, model calls, findings, and coverage. OpenAI, Anthropic, and Gemini transports have local HTTP fixtures. Invalid JSON, unsupported findings, and citations outside changed new-file lines fail visibly. Root and selected-folder instructions are loaded with a size cap.
2. **GitHub Action adapter:** TypeScript 7 handles events, credentials, PR metadata, comments, and sticky review state. The Go engine chooses files and enforces `max-files`. The Action includes a bundled JavaScript file and a Linux x64 Go executable built before the event, so it does not install dependencies while model keys are present. The PR CLI keeps `--submit` and inline comments. An empty or fully skipped review does not publish an approval summary.
3. **PR and local conversation:** `@open-review` questions use bounded diffs, selected file excerpts, thread history, follow-up suggestions, citation checks, and bot-loop protection. The old mention spelling remains accepted for existing threads. Local `ask --repo` reads bounded tracked source, keeps a short conversation, and flags unverifiable line citations.

## Compatibility and limits

The prior TypeScript fast reviewer and its tests remain in the source tree for comparison. Current Action and PR CLI fast-review callers use Go. Deep/RLM review remains TypeScript until its planned migration. The packaged Action targets Linux x64; local PR CLI use can run Go from source. The Go model path caps a review at 20 model calls and reports an error instead of silently omitting files.

The release gate runs Go tests and vet; TypeScript 7 lint, build, typecheck, and tests; process-contract fixtures; and isolated checks of the packaged Action and Go executable. Live model quality and live GitHub PR posting have not been established without model credentials. No npm, PyPI, crates.io, or Go registry publication is part of this release.
