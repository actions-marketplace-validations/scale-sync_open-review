# v0.6.0 — visible review scope

The commit for this batch uses October 6, 2026 as its Git author and committer date, following the requested sequence. GitHub displays the actual publication date.

## Added

1. **Faithful diff model:** retain each full patch, changed hunk, old and new path, Git-detected rename or copy, deletion, binary marker, and untracked marker. A per-file model no longer depends on parsing model prompts.
2. **Deterministic file selection:** support repeated `--include` and `--exclude` globs, generated and dependency defaults, supported-file rules, and file and patch limits. Each excluded file has a reason. Explicit includes override defaults but never unsafe inputs or size limits.
3. **Coverage manifest and preview:** `--preview` shows selection without a model call. Completed results mark files `reviewed`, `partial`, or `skipped`; bridge errors mark attempted files `failed`. The pull request Action now applies `max-files` to the actual diff sent to the reviewer and logs its selected and skipped files.

## Coverage states verified in fixtures

`selected`, `reviewed`, `partial` (`budget_truncated`), `skipped` (`user_excluded`, `binary_or_symlink`, `unsafe_path`, `unsafe_input`, `size_limit`, `file_limit`, `generated_or_lockfile`), and `failed` (`reviewer_failed`).

## Use from source

```bash
pnpm install --frozen-lockfile
pnpm build
go run ./cmd/open-review review --repo /path/to/repository --workspace --preview
go run ./cmd/open-review review --repo /path/to/repository --base main --head feature --include '**/*.go' --exclude 'vendor/**'
go run ./cmd/open-review review --repo /path/to/repository --commit HEAD --output json
```

The Go CLI still uses the built TypeScript bridge for a nonempty model review. The Action source remains unbundled for direct use. No package registry publication is part of this release.

## Verification

The release gate runs Git fixture tests for rename, copy, deletion, binary, and untracked changes; selection, coverage, preview, and Action model-input tests; Go vet; and the existing TypeScript build, lint, typecheck, and test suite. Live model quality and live GitHub pull request posting are not established by these fixtures.
