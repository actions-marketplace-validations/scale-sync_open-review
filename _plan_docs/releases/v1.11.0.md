# v1.11.0 — public SDK entry points

## Added

1. **Go SDK.** `github.com/scale-sync/open-review/sdk/go` exposes typed `Prepare`, `Run`, `Review`, and `Scan` functions over the existing Go review engine.
2. **TypeScript 7 SDK.** `@openreview/sdk` provides typed Node review and scan functions over the Go CLI, with `AbortSignal` cancellation and contract v2 validation.
3. **Python SDK.** `openreview-sdk` provides typed review and scan functions over the Go CLI, with timeout handling and contract v2 validation.

## Distribution and proof

The Node tarball and Python wheel/source distribution include source, metadata, and MIT license. Local empty-scan tests exercise each SDK against the built CLI without model credentials. These package names and registry ownership must be checked before npm or PyPI publication. Registry retrieval is not yet claimed.
