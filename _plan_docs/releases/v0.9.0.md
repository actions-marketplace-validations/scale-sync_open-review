# v0.9.0 — provider setup, output contracts, and bounded model use

The commits for this batch use October 9, 2026 as their Git author and committer date. GitHub shows the actual publication date.

## Added

1. **Provider setup:** interactive `config setup`, scriptable `config set`, redacted `config show`, and a live `config test`. OpenAI-compatible, Anthropic, and Gemini endpoints can be selected per run. A key can be read from standard input and stored in a private user config; environment keys take precedence.
2. **Output contracts:** Go and PR CLIs accept model overrides, quiet mode, JSON and text output, and atomic file output. The Go CLI adds Bash, Zsh, and Fish completion. Results have explicit `complete`, `partial`, `failed`, `empty`, and `skipped` statuses; local CLI exit codes are 0, 2 for partial, and 1 for error. Progress and errors go to stderr.
3. **Cost and time controls:** separate estimated prompt and output token ceilings, an aggregate token budget, request and review deadlines, usage totals, and partial results when a budget stops a review. The Action does not post partial findings as complete reviews.

## Compatibility and limits

The Go JSON contract remains version 2 with additive `model`, `limits`, and `usage` fields plus the `partial` status. Provider-reported usage is used when available; otherwise token totals are estimates. A custom endpoint requires HTTPS, except local HTTP for testing. The Action's Linux x64 bundle remains the supported packaged runtime.

The release gate includes provider configuration and redaction tests, malformed config and interrupted-response tests, unchanged output-file tests, model override and budget tests, Go tests and vet, TypeScript 7 lint/build/typecheck/tests, packaged Action and Go executable smoke checks, and GitHub CI. Live model quality and live GitHub PR posting still require credentials and a test PR. No npm, PyPI, crates.io, or Go registry publication is part of this release.
