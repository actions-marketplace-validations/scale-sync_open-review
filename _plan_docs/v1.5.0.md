# v1.5.0 — inspect whole files and past reviews

## Three features

1. **Full-file scan.** Review a selected file, directory, or repository without a Git diff using the same rules, budgets, and finding schema.
2. **Local session viewer.** Browse sessions, task evidence, coverage, and before/after comparisons in a read-only browser UI; export a self-contained report.
3. **Finding triage.** Mark findings fixed, ignored, or false positive locally and synchronize supported states with PR conversations where authorized.

## Implementation boundary

`review/internal/scan/` supplies normalized review input; it does not create a second model engine. The viewer reads session data through a narrow local API and never receives raw provider credentials. Triage writes are isolated from append-only review evidence.

## Release gate

Scan preview/resume, unsupported/binary files, viewer path scope, stored XSS, state transitions, and export tests. Verify the viewer shows partial and failed runs honestly.
